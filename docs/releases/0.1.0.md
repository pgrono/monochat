First public release of MonoChat, a desktop app for keeping multiple messaging accounts in one window on Linux.

- WhatsApp, Messenger, Google Messages, Instagram Direct, Slack and Gmail.
- Separate sessions for each account, including multiple accounts of the same service.
- Account names, ordering, muting and individual or service-wide pause controls.
- English, Polish, German, French, Spanish and Italian interface, with automatic system language selection.
- Compact sidebar, system tray support and local settings. No MonoChat account or telemetry.

### Downloads

Linux x86_64:

- **AppImage**: download, make executable and run.
- **DEB**: install on Debian/Ubuntu-based systems with the system package installer.
- **SHA256SUMS**: checksums for both packages.

Packages are built from the tagged source by GitHub Actions after type checks, lint, unit tests and Electron session-isolation tests.

Service availability and sign-in requirements are controlled by their providers. Google may restrict sign-in in embedded browsers. See [testing notes](https://github.com/pgrono/monochat/blob/v0.1.0/docs/TESTING.md) for the validation scope.
