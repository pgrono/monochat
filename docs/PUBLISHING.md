## Local Snap candidate

```sh
mkdir -p snap
cp packaging/snap/snapcraft.yaml snap/snapcraft.yaml
snapcraft
```

The recipe uses core24, GNOME extension and strict confinement. Its local unbundled directory source assumes a prior clean build; public releases must produce that directory in CI, not copy developer profiles. The `browser-support` plug requests `allow-sandbox: true`; the [interface policy](https://snapcraft.io/docs/reference/interfaces/browser-support-interface/) requires review rather than silently switching the sandbox off. Authenticated services, file portals, notifications and multimedia still need confined-package acceptance.

## Local deb license label in Zorin Software

The package declares MIT in its control metadata and now includes Debian-format copyright plus AppStream `<project_license>MIT</project_license>`. Zorin's GNOME Software 46 uses PackageKit 1.2.8 for local deb details; the APT backend emits a literal `unknown` license in `AptJob::emitPackageDetail`. This is not evidence that MonoChat has no license. The package's long description states MIT as well. Correct installed/catalog AppStream can supply richer metadata, but an uninstalled local deb may continue to show “Unknown license”. Do not patch the system package manager or promise that this generic tile is corrected by the deb control field alone.
